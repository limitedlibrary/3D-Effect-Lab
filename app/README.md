# 3D演出ラボ

Blenderで本格的に作る前に、「こういう動きにしたい」「こういう雰囲気にしたい」という演出アイデアを、簡単な3Dアニメーションですばやく試すためのWebアプリです。

破片が **集まる**／**砕けて飛び散る**／**光の粒とともに現れる・消える** の3種類の演出を、ボタンとスライダーだけで調整できます。気に入った演出は、スクリーンショット・設定JSON・メモとして保存し、あとから復元できます。

さらに **シミュレーション** では、文字や図形を立体の物体として扱い、重力・衝突・反発・摩擦・引力で動かせます。「何を動かすか」「どう動かすか」「周辺環境」をそれぞれ選んで組み合わせます。

## 起動方法

### いちばん簡単な方法
`index.html` をダブルクリックして、Chrome / Edge などのブラウザで開くだけです。

- インストールやビルドは不要です。
- 3D描画ライブラリ（Three.js）とフォントをインターネットから読み込むため、**ネット接続が必要**です。
- 前回の設定とメモはブラウザに自動で残ります（次に開いたとき復元されます）。

### GitHub Pages で公開する場合
このフォルダの中身をそのままリポジトリに置き、GitHub Pages を有効にするだけで動きます（静的ファイルのみ）。

### ローカルサーバーで開く場合（任意）
```
cd このフォルダ
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。

## 操作方法

### 3Dプレビュー
- **左ドラッグ**：視点を回転
- **ホイール**：拡大・縮小
- **右ドラッグ**：視点を平行移動
- 右上の **自動回転** でゆっくり回り続け、**視点リセット** で最初の位置に戻ります。

### 再生バー
- ▶ / ❚❚：再生・停止
- ↻：最初から再実行
- スライダー：再生位置を自由に動かせます（止めた位置の見た目で保存もできます）
- **1回 / ループ / 往復**：繰り返し方。「往復」にすると、集合→逆再生で散らばる…のように行き来します。

### キーボード
- `Space`：再生 / 停止
- `R`：最初から再実行
- `P`：スクリーンショットを保存
- 比較モード中は `Space` / `R` / `→`（シミュレーションのコマ送り）が全枠にはたらきます

### 演出の調整（右パネル）
動きに関わる項目を変えると、すぐに最初から再生されて違いが分かります（色・背景・光は再生位置を保ったまま変わります）。

**集合先の形**（破片が集まる先・壊れる元の形）
- 文字 / 球体 / 立方体 / ドーナツ
- **文字**：好きな文章を入力できます（日本語・英語・数字・記号、最大120文字）。
  - 入力をやめて約0.5秒後に、その文字の形を作り直して最初から再生します（日本語の変換中は待ちます）。
  - `Enter` で改行できます。改行しなくても、長い文は「長い文は自動で改行」がオンなら横長にまとまるよう自動で折り返します。
  - 文字数に合わせて、全体がプレビューに収まる大きさへ自動で調整します。
  - 入力欄の下の「例：」を押すと、サンプルの文字をすぐ試せます。
  - 文字数・行数と、読みやすくなる破片数の目安が表示されます。破片が足りないときは「破片数を推奨の約○個にする」を押すと調整されます。
- **フォント**：ゴシック / 明朝 / 丸ゴシック / ポップ / 手書き風 / 英字ロゴ（英字ロゴは日本語を含まないので、日本語部分はゴシックで表示されます）
- **文字の太さ**：太字 / 標準
- **行のそろえ方**：左 / 中央 / 右（複数行のとき）
- **文字の厚み**：薄い ↔ 厚い（平面の文字シルエットに奥行きを付けます）
- 入力した文字・フォントなどは、左のプリセットを切り替えても引き継がれます。どの演出（集合・破砕・出現/消滅）、配色、速度とも組み合わせられます。

**破片**
- 破片の数（200〜12000）・大きさ・形（三角 / 四角 / かたまり）
- 🎲 ばらつきを変える：破片の配置や散らばり方の乱数を変えます

**動き**
- 再生時間：速い ↔ 遅い
- 動き方：直線的 / 回転しながら / 渦を巻く
- 破片の広がり：狭い ↔ 広い
- 緩急：なめらか / すっと止まる / 一定 / 弾む
- 動き出す順番：ランダム / 下から / 上から / 左から / 中心から
- 時間差：一斉に ↔ ばらばら

**演出ごとの設定**
- 集合：最初の散らばり方（空間全体 / 床に散らばる / 輪になる / 上から降る）
- 破砕・飛散：飛ぶ方向（全方向 / 上へ / 横へ / 手前へ）、飛ぶ速さ、重力、最後に消える
- 出現・消滅：種類（出現 / 消滅）、粒子の流れ（上へ昇る / 外へ広がる / その場で）

**見た目**
- 色（書庫 / 氷 / 炎 / 森 / ネオン / モノクロ）、背景（暗い / 薄暗い / 明るい）、光の強さ、光の粒、床のグリッド
- 質感：標準 / 金属寄り / マット / つや（破片・シミュレーションの物体のマテリアル。標準は従来と同じ見た目）
- 照明の向き：基準 / 逆光 / 横から / 真上から / 正面から、照明の強さ（0.2〜2倍。基準・1倍で従来と同じ明るさ）

### 比較モード（2〜4枠で見比べる）
プレビュー右上の **⧉ 比較モード** で、編集中の演出を2〜4枠に並べます。
- **候補の自動生成**：A枠には編集中の案（設定一式と視点）をそのまま置き、B〜D枠には構図と見た目を変えた候補が最初から並びます。手で調整しなくても、同じ再生位置で違いを見比べられます。
  - 構図：注視点はそのままに、カメラを左右に回り込ませ（約20〜35°）、高さ（高め / 低め）や距離（寄り / 引き）を変えます。被写体が画面の外に出たり極端に小さくなったりしにくい範囲に収めます。
  - 見た目：質感（標準 / 金属寄り / マット / つや）・色・照明（向き・強さ）のうち、候補ごとに1〜2項目を選んで変えます（全項目を一律には変えません。背景・光の強さ・光の粒・グリッドは変えません）。
  - どの候補も構図と見た目の両方を変えるので、2枠でも両方の違いを確認できます。どの項目を変えるかは比較を開くたびに変わります。
- **並べる数**：2枠 / 3枠 / 4枠（最初は4枠）。減らした枠の設定は、増やし直すと戻ります。
- **再生は全枠で共通**：下の再生バー（再生・停止・最初から・再生位置・繰り返し）と `Space` / `R` が全枠にはたらきます。シミュレーションでは コマ送り（`→`）も全枠そろって進み、同じ再生位置の物体の動きを違う視点で見比べられます。
- **枠ごとの調整**：枠をクリックして選ぶと（金色の枠）、右パネルでその枠だけのカメラ・見た目を変えられます。ほかの枠の設定はそのままです。
  - カメラ：元の視点 / 自動の候補（B〜D枠のみ。自動で決めた構図に戻す）/ 低い / 高い / 横から / 寄り。枠の中をドラッグ・ホイールで自由に動かすこともできます（見出しが「カメラ：調整」になります）。
  - 照明（向き・強さ）、質感・色・背景・光の強さなど（右パネルの「見た目」と同じ項目）
  - 動き（形・破片・動き・物理のルールなど）は全枠で共通です。変えたいときは1画面に戻って編集します。
- 枠の左上には、A枠（基準）から変えた点（例：「B｜カメラ：右から 高め・質感：マット」「C｜照明：逆光」）が表示されます。
- **この案から比較**（枠の右下・右パネル）：その枠の設定一式を起点に、新しい比較（比較2、比較3…）を作ります。A枠にはその案の構図・質感・色・照明がそのまま入り、残りの枠にはその案から構図や見た目の一部を少しだけ変えた候補（回り込み約10〜18°、照明の強さだけ変えることもある）が並びます。新しい比較で何を変えても元の比較は変わらず、右パネル上の一覧から元の比較へいつでも戻れます（自動の候補も手動調整もそのまま残ります）。
- **採用**：その枠の設定（見た目・照明・質感・視点を含む）を引き継いで1画面編集に戻ります。そのまま続けて編集・保存・Blenderへの出力ができます。
- **比較をやめる**：比較を始める前の編集状態のまま1画面に戻ります。
- 比較の履歴は、ページを開いている間だけ保持されます（再読み込みすると消えます）。比較モード中は、設定の読み込み・スクリーンショット・Blenderへの出力はできません（採用して1画面に戻ってから行います）。

### シミュレーション（左パネルの「シミュレーション」）

タイムライン型の演出（集合・破砕・出現/消滅）は「再生位置を決めれば見た目が決まる」アニメーションです。シミュレーションは「前の状態から1/60秒ずつ計算を進める」物理演算で、別の仕組みとして動きます。

**サンプル**
- 文字が落ちて跳ねる：「有限書庫」が1文字ずつ空中から落ち、床で跳ねて止まります（「有」は重くて跳ねにくく、「庫」は軽くてよく跳ねる設定）
- 文字全体で落下：文章全体を1つの物体として落とします
- 空中に整列：床に転がった文字が引き寄せられて、空中の指定位置に並びます（薄い影が目標の位置です）
- 落ちてから整列：落下して散らばった後、元の並びへ戻ります
- 箱の中ではじける：壁で囲んだ中に図形を落とし、中心から反発力ではじき飛ばします
- 斜面を転がる：球・円柱・立方体が斜面を転がって障害物にぶつかります
- 斜面の立方体と円柱：上と同じ斜面で、5秒・6個に絞った版（Blenderへの出力の検証用）

**右パネル**
- 動かすもの：文字 / 基本図形（立方体・球・円柱・ミックス、数）
  - 文字の動かし方：**1文字ずつ**（それぞれ別の物体）／**全体で1つの物体**
  - 文字・フォント・太さ・そろえ方・厚みは「集合」と同じ入力欄で変えられます。文字は輪郭から作った本物の立体で、衝突も文字の形（細かな箱の組み合わせ）で判定します
  - 最初の置き方（並んだまま空中 / ばらばらに空中 / 床に置く）、落とす高さ、最初の傾き・ばらつき
  - **1つずつの重さ・跳ね返り**：文字ごとにスライダーで変えられます。変えた文字は枠が金色になり、「すべて基本の値に戻す」で元に戻ります
- 動きのルール：重力（無重力〜地球の2倍）、重さ（基本）、反発（跳ね返り）、摩擦、空気抵抗
  - 引力・反発力：なし / **指定位置へ整列** / **一点に引き寄せる** / **中心から反発**。はたらき始める時刻・力の強さ・目標の高さを選べます
  - 計算する長さ、再生速度（1/4スロー〜2倍）
- 環境：床（ぶつかる／突き抜ける）、壁（なし・奥だけ・左右・四方を囲む）、障害物（＋箱・＋柱・＋斜面を最大8個。位置・大きさ・角度を調整、削除）
- 色・背景・光の強さも使えます（色を変えても計算は最初からやり直しません）

**再生バー（シミュレーションのとき）**
- ▶ / ❚❚：再生・一時停止（一時停止した場所からそのまま続きを計算します）
- ↻（`R`）：**初期状態へリセット**（止まった状態で最初に戻ります。`Space` で再生）
- ⏭（`→`）：コマ送り（1/60秒だけ進める）
- スライダー：再生位置の移動。戻すときは初期状態から同じ回数だけ計算し直すので、同じ場面が再現されます
- 1回 / ループ（「往復」はシミュレーションでは使いません）
- 設定を変えると、初期状態から計算し直して再生します

**再現性**：初期配置は設定と乱数の種（🎲 ばらつきを変える）だけで決まり、計算は描画の速さに関係なく1/60秒刻みで進むので、同じ設定なら同じ動きになります（同じブラウザ・同じPCの場合）。

### アイデアの記録（左パネル下）
- **メモ欄**：思いついたことを書いておけます（自動で一時保存されます）
- **📷 スクリーンショット**：今のプレビューをPNGで保存
- **⬇ 設定を保存**：設定内容・メモ・再生位置・カメラ位置をJSONで保存
- **⬆ 設定を読み込む**：保存したJSONから設定を復元（JSONをプレビューにドラッグ＆ドロップしても可）
- **まとめて保存**：PNGとJSONを同じ名前で一度に保存
- **Blenderで組み立てるときのメモ**：今の設定を Geometry Nodes やキーフレームでどう組むかの手がかりを表示します（JSONにも `blenderHints` として入ります）。
- **⇪ Blenderへ出力**（シミュレーションのとき）：動きをフレームごと（30fps / 60fps / 24fps）に記録したJSONを保存します。`blender/lab_to_blender.py` で読み込むと、Blender上にキーフレーム付きのオブジェクトとして再現されます。詳しくは [blender/README.md](blender/README.md)

## 機能を追加するには

- **新しい演出**：`js/effects/` に `gather.js` をまねたファイルを作り、`index.html` に `<script>` を1行追加します。演出は「時刻 t（0〜1）のとき、各破片がどこにいて、どれくらい光っているか」を返す関数を書くだけで、再生・調整・保存の仕組みはそのまま使えます。
- **新しい設定項目**：`js/params.js` の一覧に1行追加すると、右パネルとJSONに自動で反映されます。
- **新しいプリセット**：保存したJSONの `params` を `js/presets.js` に貼り付けると、左パネルに並びます。
- **新しい集合先**：`js/targets/` にファイルを作り、`Lab.registerTarget()` で登録して `params.js` の「集合先の形」の選択肢に足します。集合先は「文字（text）」「基本図形（primitive）」「画像・ロゴ（image）」の3分類を想定しています。
  - 画像・ロゴは、`text.js` と同じく「画像をキャンバスに描く → 塗られた（または明るい）ピクセルから点を拾う」方法でそのまま追加できます。読み込んだ画像の扱い以外は、演出・保存の仕組みを共有します。

- **シミュレーションの拡張**：3つの部品を独立して足せます。
  - 何を動かすか：`Lab.registerSimSubject()`（例：GLBモデル、キャラクター、関節を持つ物体）
  - どう動かすか：`Lab.registerSimRule()`（例：目標地点へ向かう、障害物を避ける）
  - 周辺環境：`js/sim/environment.js` の `OBSTACLES` に種類を追加
  - 物理エンジンには Rapier を使っているので、関節（ジョイント）なども同じワールドに追加できます。

## 長い文でも重くならない工夫
- 文字を描くキャンバスに上限（最大2400px・約220万ピクセル）を設け、長文は描画サイズを自動で下げます。
- 一度描いた文字の形はキャッシュし、破片数や演出・色を変えても描き直しません。
- 入力中は形を作り直さず、入力が止まってから1回だけ作り直します。
- 破片の数は文字数ではなく「破片の数」の設定で決まるので、文字が増えても描画の重さは変わりません（長文で破片を増やしたいときは推奨数ボタンで調整）。

## 動作環境
- PC版の Chrome / Edge / Firefox / Safari（WebGL対応ブラウザ）
- Three.js r160（CDN: jsDelivr）
- 物理エンジン：Rapier（@dimforge/rapier3d-compat 0.14.0、CDN: jsDelivr。シミュレーションを初めて開いたときだけ読み込みます）
- フォント（Google Fonts）: Noto Sans JP / Noto Serif JP / M PLUS Rounded 1c / Dela Gothic One / Yomogi / Bebas Neue
